# Andrew's Construction website

Open `index.html` in a web browser to view the site.

To customize it:
- Replace the project photos in `style.css`.
- Update the contact form in `index.html` with your real contact information.
- Change the services or text to match the actual business.
- For a public website, upload these files to a hosting service.

This is a starter/demo website. It does not currently send form submissions to an email address.
